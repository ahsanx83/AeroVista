# Skybound Seat Reservations

Create the Air Ticket reservation system project maintaining design patterns and SOLID principles, apply validations in frontend, make react UI lucrative with tailwind CSS and use MySQL DB without using containerization, populate data with free data from internet, create both user log in and admin log in. Use JWT authentication and authorization that requires secret key to decode JWT token
